一键安装脚本

复制下方命令，粘贴到服务器终端执行即可完成部署。所有脚本均支持 Alpine、Debian、Ubuntu 主流发行版。

使用说明

硬件与系统要求

  • 运行内存大于等于 100M
  • 存储空间大于等于 1G
  • 使用 Alpine3.20+、Debian11+、Ubuntu18+ 系统

注意事项

  • 请务必使用 root 用户执行安装命令。
  • 执行前请确保服务器能正常访问互联网（含 GitHub）。
  • 如遇权限问题，请在命令前加 sudo 或切换到特权用户。
  • GitHub 下载缓慢或失败时可用镜像：SB_MIRROR=https://ghfast.top/ bash 脚本名.sh
