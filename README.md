## 📋 项目概述

本项目提供一组用于快速部署 **Sing-box** 的 Shell 脚本，覆盖落地机与中转机场景，支持Alpine3.20+、Debian11+、Ubuntu18+ 系统。

> **项目主页：** [https://script.rr.kg](https://script.rr.kg)

---

## 📦 脚本列表

| 脚本 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| [`install-singbox-lite.sh`](#基础安装脚本) | 基础安装脚本 | 常规部署环境 |
| [`install-singbox-lite-SANs.sh`](#支持-san-证书的安装脚本) | 含 SANs 证书支持的安装脚本 | 需要自定义证书的场景 |
| [`zzj.sh`](#中转机脚本) | 中转机脚本 | 搭配落地机使用 |
